Reflection 

For this redesign, I improved the layout and appearance of my personal website and organized the files into folders. I used semantic HTML elements such as `header`, `nav`, `main`, `section`, `article` and `footer` to make the page easier to understand. I also updated the CSS with Grid, Flexbox and media queries so the content can adjust to different screen sizes. I added a local illustration, kept online project images, included alt text and added comments to explain important parts of the code.

One challenge was making the page fit smaller screens without making the text or navigation difficult to use. I worked on this by stacking the main sections on mobile and adjusting the spacing and image heights. I also learned that a website needs more than a good desktop design; it should be checked on phones and tablets too.

The GitHub workflow is another important part of the assignment. A separate branch lets me work on redesign changes without changing the main version straight away. Commits should explain what changed, and a Pull Request gives me a chance to review the work before merging it into `main`. I still need to complete the branch and Pull Request steps in my GitHub repository and capture screenshots from the actual browser at mobile, tablet and desktop sizes.
